# Musical Keyboard

A simple, high-quality musical keyboard you can play with your laptop keys. Two octaves, white and black keys, with a piano-style frontend.

## Run the app

**Option 1 – Local server (recommended)**

```bash
npm run
```

Then open **http://localhost:3000** in your browser.

**Option 2 – Using Python**

```bash
python3 -m http.server 3000
```

Then open **http://localhost:3000**.

**Option 3 – Open file directly**

Open `index.html` in your browser (double-click or drag into the window). Click the page once to enable sound, then play.

## Controls

- **White keys:** `A` `S` `D` `F` `G` `H` `J` `K` `L` `;` `'` `Z` `X` `C`
- **Black keys:** `W` `E` `T` `Y` `U` `I` `O` `P` `[` `]`

Click the hint area or press any key once to enable sound (required by the browser).
